# Toy Wholesale Marketplace WebApp (PlayJoy)

PlayJoy is now a complete static storefront built with HTML, CSS and vanilla JavaScript. It requires no build step or framework and can be deployed directly to Vercel.

## Storefront Pages

- `index.html` — Stitch-matched homepage
- `shop.html` — searchable, filterable product catalog
- `product_details.html` — product gallery, details and B2B options
- `cart.html` — persistent shopping cart with quantity controls
- `checkout.html` — validated delivery/payment form and order confirmation
- `get_a_sample.html` — two-step B2B sample request
- `account.html` — login and registration UI
- `about.html` and `contact.html` — company, support and FAQ pages
- `admin_panel.html` — inventory/admin prototype
- `404.html` — custom not-found page

Cart data is stored in the browser with `localStorage`. Forms are front-end demos and are ready to be connected to a real commerce/payment backend later.

## Run Locally

Open `index.html` directly, or serve the folder with any static server:

```bash
npx serve .
```

## Deploy to Vercel

1. Import this folder/repository into Vercel.
2. Choose **Other** as the framework preset.
3. Leave the build command empty.
4. Set the output directory to `.` and deploy.

`vercel.json` already enables clean URLs and basic security headers.
